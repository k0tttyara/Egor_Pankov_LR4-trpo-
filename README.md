# ComputerShop — WPF-приложение «Онлайн-магазин компьютерной техники»

Учебный проект: WPF + ADO.NET (System.Data.SqlClient) + SQL Server LocalDB.

## Требования
* Visual Studio 2019/2022 с рабочей нагрузкой «Разработка классических приложений .NET»
* .NET Framework 4.8 (входит в состав Windows)
* SQL Server LocalDB (устанавливается вместе с Visual Studio)

NuGet-пакеты НЕ нужны — проект собирается без доступа к интернету.

## Запуск
1. Распаковать архив, открыть ComputerShop.sln
2. Нажать F5 — база ComputerShopDB создаётся и заполняется автоматически при первом запуске

## Демо-аккаунты
* admin / admin123 — Админ
* manager / manager123 — Менеджер
* user / user123 — Клиент

## Роли
* Клиент — каталог (поиск и фильтр по категориям), корзина, оформление заказа, отмена своего заказа со статусом «Новый»
* Менеджер — все заказы, изменение статуса
* Админ — то же, что менеджер, плюс удаление заказов (товар возвращается на склад)

## Реализация
* Оформление заказа — транзакция: списание товара со склада, если остатка не хватает — откат
* Отмена/удаление заказа — возврат товара на склад
* Пароли хранятся в виде SHA-256 хеша
* Валидация ввода: ФИО, логин, длина пароля, e-mail, количество
* Все операции с БД — через SqlClient с параметрами, ошибки перехватываются и выводятся пользователю
